Add New Product

Only the product image is required — everything else is optional.

Add one row per size + color combination you stock, with how many units you have (e.g. S Green 1, S Blue 2). Size can be anything — letters like S/M/L, or a measurement like "6 inches" or "6-8 inches" for items sized by length. Leave Size and/or Color blank if not needed.

By default every color shows the same Product Images above. If a color (e.g. "Blue") should show its own photos instead, add it here with its own image(s). Colors left out just use the default images.

Inventory

Products you add here appear on the shop, filterable by category.

Orders

Every order placed through "Checkout via Instagram" is recorded here with the customer's contact details, so you can follow up and fulfill it. Mark an order as Sold once it's been paid for and shipped.

Customers

Built automatically from order details — every customer who checks out is added or updated here.

Announcements

Send a bulk message to all customers who have an email on file — for sales, new arrivals, or discounts. This opens your email app with everyone's address pre-filled in BCC, so you can review and send it yourself.
